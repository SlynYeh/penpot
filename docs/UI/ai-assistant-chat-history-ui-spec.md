## 一、通用结构（两视图共有）

### 1. 顶部 Tab 栏

位于面板最顶部，三段式分段控件（segmented control）。

- 容器：浅灰蓝底色、大圆角长条，横向三等分，三个标签均分宽度。
- 三个标签从左到右：
  1. **设计** —— 未选中态；
  2. **AI助手** —— 当前选中态；
  3. **检查** —— 未选中态。
- 选中态（AI助手）：
  - 底色：白色圆角浮起块，位于分段容器中间；
  - 前置图标：蓝色折线 / X 形图标（蓝到青的渐变）；
  - 文字：紫蓝色，与图标横向居中排列；
  - 文字前有一个蓝色小图标 + 文字「AI助手」。
- 未选中态（设计 / 检查）：深灰蓝色文字，无图标、无底色，居中对齐。

```
┌───────────────────────────────────────────────┐
│       设计        ┌───────────────┐    检查   │
│                  │ 𝕏 AI助手      │           │
│                  └───────────────┘           │
└───────────────────────────────────────────────┘
```

### 2. 页面背景与滚动

- 页面底色：白色（消息流区域）；输入卡片下方区域为极浅灰。
- 消息流 / 列表区域为纵向滚动容器，右侧细灰色滚动条。

## 二、会话视图（IMG_4245）

### 2.1 顶部操作行

Tab 栏下方、消息流上方，左对齐横排两个「图标 + 文字」扁平入口按钮，无背景、无边框、无圆角底色：

| 顺序 | 图标（截图视觉） | 文案 | 说明 |
|---|---|---|---|
| 1 | 定位 / 靶心状轮廓图标（圆点 + 外框） | **新对话** | 深灰蓝图标与文字 |
| 2 | 逆时针环形箭头图标（C 形回旋箭头） | **历史对话** | 深灰蓝图标与文字；点击进入历史对话视图（IMG_4244） |

两个按钮之间留水平间距，文字垂直居中于图标右侧。

```
┌───────────────────────────────────────────────┐
│ ◉ 新对话      ↺ 历史对话                       │
└───────────────────────────────────────────────┘
```

### 2.2 消息流区

消息流自上而下排列；用户消息右对齐，AI 消息块左对齐、通栏宽度。

#### 2.2.1 用户消息气泡

- 位置：右对齐，贴近右侧内容边距。
- 容器：浅灰色圆角矩形气泡（圆角较大），无描边。
- 文案（照抄）：**设计一个用户管理的列表页面**
- 文字：深灰色，常规字重，单行。

```
                              ┌─────────────────────────────┐
                              │ 设计一个用户管理的列表页面   │
                              └─────────────────────────────┘
```

#### 2.2.2 AI 消息块（左对齐，通栏）

AI 消息块自上而下由「头像 → 若干状态条目 → 正文段落 → 判定列表 → 引导句 → 提问卡片」组成。

**A. AI 头像**

- 圆形，位于消息块左上角；
- 底色：蓝紫渐变（紫到蓝）；
- 内部：白色机器人 / 星形图案（细节待设计稿确认）。

**B. 状态条目行（图标 + 文字，灰蓝色，左对齐）**

消息块中重复出现两组相同条目，分别位于两段正文之前：

1. **技能加载条目**
   - 图标：拼图块 / 齿轮状轮廓图标；
   - 文案（照抄）：**加载技能：招乎文档原型设计V2**
2. **深度思考条目**
   - 图标：双方框 / 大脑状轮廓图标；
   - 文案（照抄）：**深度思考**

条目行文字为灰蓝色辅助色，图标与文字垂直居中，行间距小于正文段落间距。

**C. 正文段落（深灰黑色，常规字重，行内代码高亮）**

段落中出现的代码名 / 文件名使用行内代码样式：浅灰底、圆角、等宽字体、深色文字，与正文同一基线内联。

**段落 1（照抄）：**

> 根据安全与流程规范，`penpot-work-flow` 是 phase 2 内部执行技能，禁止被用户请求直接触发，必须由 `penpot-master` 完成阶段 1（意图识别、需求补全、构建 `prompt.txt`）后进入阶段 2 时才能加载。

行内代码串：`penpot-work-flow`、`penpot-master`、`prompt.txt`。

**段落 2（照抄）：**

> 你直接发起了「设计一个用户管理的列表页面」，正确的入口是 `penpot-master`。我将通过该入口启动完整工作流来为你生成页面设计。

行内代码串：`penpot-master`。

**D. 第二组状态条目**

依次重复：

- 加载技能：招乎文档原型设计V2
- 深度思考

**E. 段落 3（照抄）：**

> 我已进入 `penpot-master` 主调度流程（阶段 1：意图识别与需求补全）。

行内代码串：`penpot-master`。

**F. 判定结论区**

- 引导小标题（照抄）：**初步判定：**
- 下方为圆点无序列表，三条，列表项左缩进、圆点为深色实心小圆点：

  1. **输入端类型：** 你描述的是「用户管理」列表页（含"管理"一词）→ 判定为 PC 端·中后台系统
  2. **场景类型：** 未含 App/App 关键词 → toB 场景
  3. **页面类型：** 用户管理列表页（单页面）

  - 每条内「→」为箭头分隔；判定结论部分（如「PC 端·中后台系统」「toB 场景」「用户管理列表页（单页面）」）与前文同色，未做加粗或变色处理（截图所见）。
  - 列表项支持换行，第二行相对于文字起点缩进对齐（非悬挂到圆点）。

> 备注：第 2 条「App/App」按截图原样记录，第二个词疑为「App / 小程序」或其他，见文末「待确认」。

**G. 提问引导句（照抄）：**

> 为了让生成的界面更贴近你的需求，需先确认以下信息（一次问完）：

**H. 提问条目行**

- 图标：圆圈内一横 / 问号轮廓图标；
- 文案（照抄）：**询问用户问题**
- 灰蓝色辅助文字，样式同「深度思考」条目行。

**I. 提问卡片（问题卡片）**

- 容器：白色圆角描边卡片，浅灰细边框，通栏宽度；
- 卡片上部为问题文字，下方有一条水平浅灰分隔线；
- 问题文案（照抄）：**这个用户管理列表页需要具备哪些核心操作能力？（可多选）**
- 卡片右侧外悬浮一个竖向白色圆角小浮层（带轻微阴影），分上下两段：
  - 上段：方形，蓝色描边、白底，内部居中一个橙红色数字 **1**；
  - 下段：白底，内部居中一个橙红色向下 V 形箭头（折叠 / 展开指示）。

```
┌──────────────────────────────────────────────┐   ┌──────┐
│ 这个用户管理列表页需要具备哪些核心操作能力？  │   │  1   │
│ （可多选）                                     │   ├──────┤
│ ───────────────────────────────────────────── │   │  ▾   │
└──────────────────────────────────────────────┘   └──────┘
```

### 2.3 底部输入区

固定在消息流下方的输入卡片，白色大圆角容器，通栏宽度，内部分上下两个功能行。

**上行（输入占位行）：**

- 占位文字（照抄）：**分配一个任务或提问任何问题...**
- 颜色：浅灰色占位符样式；左对齐，距卡片左侧内边距。

**下行（工具行，左右分布）：**

左侧：

1. **角色标签**：浅橙 / 米黄色底色胶囊（圆角药丸），内部橙红色文字 **原型设计师**；
2. **附件图标**：回形针轮廓图标，深色描边，位于角色标签右侧，留水平间距。

右侧（从左到右依次排列）：

3. **书本 / 双页图标**：黑色描边，打开的书本形状；
4. **麦克风图标**：黑色描边，麦克风形状；
5. **停止按钮**：橙红色圆角方块按钮，内部居中一个白色小方块（停止 / 结束生成态）。

**卡片外侧右边缘：**

- 一个白底半圆角按钮，内嵌左尖括号 **‹**（收起 / 折叠面板指示），半挂在输入卡片右侧外沿。

```
┌────────────────────────────────────────────────────────┐
│ 分配一个任务或提问任何问题...                             │
│                                                          │
│ [原型设计师]  📎                          📖  🎤  ■  │
└──────────────────────────────────────────────────────┘‹
```

> 按钮启用 / 禁用态、发送态（停止按钮在可发送时是否变为发送箭头）截图未体现，见「待确认」。
