# 重要快捷键tab-content UI定制需求

重要快捷键内容列表单独使用与其它兄弟tab内容不同的UI布局样式，文档中没提到的信息你可以和我确认

## 总体布局方式

两行四列

windows
| 穿透选择  Ctrl 点击 | 多选图层  Shift 点击 | 拖动画布  空格 拖动 | 新建文本  T |
| 取消选择/退出编辑  Esc | 放大/缩小画布  Ctrl 滚轮 | 画板  A / B | 创建编组  Ctrl G |

mac
| 穿透选择  ⌘ 点击 | 多选图层  ⇧ 点击 | 拖动画布  空格 拖动 | 新建文本  T |
| 取消选择/退出编辑  ⎋ | 放大/缩小画布  ⌘ 滚轮 | 画板  A / B | 创建编组  ⌘ G |

## 列表项细节

- 列表项内容分两行，第一行显示label 和 键位信息，第二行显示快捷键功能描述
- label：字体16px、700
- 描述信息：字体12px、400、#495e74
- 其它未提及的延用原有样式
