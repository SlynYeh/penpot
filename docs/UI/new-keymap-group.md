# 快捷键分组
底部浮层的快捷键面板分组列表，含windows、mac双平台

## 重要快捷键

windows
| 穿透选择  Ctrl 点击 | 多选图层  Shift 点击 | 拖动画布  空格 拖动 | 新建文本  T |
| 取消选择/退出编辑  Esc | 放大/缩小画布  Ctrl 滚轮 | 画板  A / B | 创建编组  Ctrl G |

mac
| 穿透选择  ⌘ 点击 | 多选图层  ⇧ 点击 | 拖动画布  空格 拖动 | 新建文本  T |
| 取消选择/退出编辑  ⎋ | 放大/缩小画布  ⌘ 滚轮 | 画板  A / B | 创建编组  ⌘ G |

mac

| 画板  A | 铅笔  ⇧ C | 显示/隐藏界面  \ |
| 文本  T | 椭圆  E | 显示/隐藏调色盘  ⌥ P |
| 矩形  R | 取色器  I | 显示/隐藏字体调色盘  ⌥ T |

## 选择
windows
| 穿透选择  Ctrl 点击 | 选择子级  回车 |
| 全选 Ctrl A | 选择父级  Shift 回车 |
| 取消选择  Esc | 选择下一个图层  Tab |
| 测量距离  Alt 悬停目标图层 | 选择上一个图层  Shift Tab |

mac
| 穿透选择  ⌘ 点击 | 选择子级  ⏎ |
| 全选  ⌘ A | 选择父级  ⇧ ⏎ |
| 取消选择  ⎋ | 选择下一个图层  Tab |
| 测量距离  ⌥ 悬停目标图层 | 选择上一个图层  ⇧ Tab |

## 缩放
windows
| 拖动画布  空格 拖动 | 全览  shift 1 |
| 放大  Ctrl + / 滚轮 | 缩放至选中图层  Shift 2 |
| 缩小  Ctrl - / 滚轮 | 放大特定位置  Z 点击 |
| 缩放至100%  Shift 0 | 缩小特定位置  Alt Z 点击 |

mac
| 拖动画布  空格 拖动 | 全览  ⇧ 1 |
| 放大  ⌘ + / 滚轮 | 缩放至选中图层  ⇧ 2 |
| 缩小  ⌘ - / 滚轮 | 放大特定位置  Z 点击 |
| 缩放至100%  ⇧ 0 | 缩小特定位置  ⌥ Z 点击 |

| 创建编组  Ctrl G | 垂直翻转  Shift V | 上移一层  Ctrl ↑ |  |

mac

| 搜索图层名称  ⌘ F | 水平翻转  ⇧ H | 锁定/解锁图层  ⌘ ⇧ L | 移至底层  ⌘ ⇧ ↓ |
| 创建编组  ⌘ G | 垂直翻转  ⇧ V | 上移一层  ⌘ ↑ |  |
| 取消编组  ⇧ G | 重命名图层  ⌥ N | 下移一层  ⌘ ↓ |  |
